# Севермакс — SMS-пульт для подогревателя 5000 4-mini

Android-приложение для управления предпусковым подогревателем Севермакс 5000 4-mini
через GSM-модуль салонного пульта.

## Возможности
- Запуск / остановка, запуск на заданное время (10–120 мин), запрос статуса.
- Ползунок температуры (NFPZ\*XX или CGPZ\*XX — зависит от прошивки).
- Режим догрева: два ползунка порогов (разница ≥ 10°C), приложение отправляет
  XHPZ\*ВЕРХ\*НИЗ, ждёт ответ «XHPZ OK!» и само отправляет K. Кнопка XHPZ OFF.
- Привязка номера телефона в слоты A–D (TJSQ\*код\*A).
- Журнал: статус каждой SMS (отправлено / нет сети / нет баланса), ответы подогревателя,
  расшифровка кодов ошибок E-01…E-12 с рекомендациями. Ответы ловятся даже когда приложение закрыто.
- Защита от повторного запуска раньше 3 минут после остановки.
- Автомобиль: 88 марок и больше 1100 моделей, поиск по-русски, своя модель, госномер, фото.
- Кнопка «Поддержи разработку».

## SMS-команды
| Команда | Действие |
|---|---|
| `K` | Запуск (30 минут) |
| `K*040` | Запуск на 40 минут, однократно |
| `G` | Остановка |
| `C` | Статус |
| `NFPZ*65` / `CGPZ*65` | Температура 65°C (без запуска) |
| `XHPZ*90*30` | Пороги догрева, затем `K` |
| `XHPZ OFF` | Выключить догрев |
| `TJSQ*123456*A` | Привязать номер (слоты A–D) |

## Сборка на GitHub
1. Загрузите содержимое архива в корень репозитория (вместе с папкой `.github`).
2. Сборка запустится сама (вкладка **Actions**), занимает ~5 минут.
3. Готовый файл: **Releases → latest → severmax.apk**
   (прямая ссылка: `https://github.com/ЛОГИН/РЕПОЗИТОРИЙ/releases/latest/download/severmax.apk`).

Все сборки подписаны одним ключом (`app/signing/severmax.jks`), поэтому новая версия
ставится поверх старой без удаления — настройки, фото и журнал сохраняются.
Ключ лежит в репозитории: держите репозиторий приватным. Для публикации в RuStore / Google Play
создайте отдельный секретный ключ.

## Установка на телефон
- При установке Google Play Защита может предупредить о приложении с доступом к SMS —
  выберите «Всё равно установить».
- При первом запуске разрешите отправку и приём SMS. Если разрешение не выдаётся:
  Настройки → Приложения → Севермакс → Разрешения → SMS → Разрешить
  (на некоторых телефонах сначала ⋮ → «Разрешить ограниченные настройки»).
- На Xiaomi/Redmi дополнительно: Разрешения → «Отправка SMS» → Разрешить.

## Структура
- `app/src/main/assets/www/` — интерфейс (index.html, app.js, cars.js). Открывается и в обычном
  браузере в демо-режиме — удобно править дизайн без сборки.
- `MainActivity.kt` — WebView, отправка SMS со статусом, выбор фото, кнопка «Назад».
- `SmsReceiver.kt` — приём ответов подогревателя (только с номера подогревателя).
